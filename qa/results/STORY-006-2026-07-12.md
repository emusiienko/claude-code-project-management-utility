## Root Cause
The frontend implementation of STORY-006 was not deployed. The Task Detail Modal still renders the placeholder from before STORY-006 ("Task links — coming in STORY-006"). The Story slide-over right panel has no Links section at all.

Additionally, the backend API endpoints for task-links and story-links (POST/GET /v1/tasks/{id}/links, POST/GET /v1/stories/{id}/links, DELETE /v1/task-links/{id}, DELETE /v1/story-links/{id}) are not registered in the router — they return 404.
