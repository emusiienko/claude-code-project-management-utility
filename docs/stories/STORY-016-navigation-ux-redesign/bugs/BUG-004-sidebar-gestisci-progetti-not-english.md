# BUG-004: Sidebar "Gestisci Progetti" link text is not in English

## Description

The link at the bottom of the project sidebar reads "Gestisci Progetti" (Italian). The UI language is English.

## Steps to Reproduce

1. Open the app in a browser.
2. Select any project to enter the project context (sidebar visible).
3. Scroll to the bottom of the sidebar.
4. Observe the link text.

## Expected Result

The link should read "Manage Projects" (English).

## Actual Result

The link reads "Gestisci Progetti" (Italian).
