# BUG-002: /settings page has no margins

## Description

The content on the Global Settings page (`/settings`) renders flush against the viewport edges — no horizontal or vertical padding/margin around the content area.

## Steps to Reproduce

1. Open the app in a browser.
2. Click the gear (⚙) icon in the top navigation bar to navigate to `/settings`.
3. Observe the spacing between the page content and the viewport edges.

## Expected Result

Consistent margins matching the rest of the app (similar to the project sub-screens).

## Actual Result

The content renders with no horizontal or vertical padding, flush against the viewport edges.
